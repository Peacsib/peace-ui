> **Peace UI** is Peace Sibanda's signature design engineering philosophy and UI system for high-trust institutional platforms across **fintech, banking, edtech, and enterprise applications**.

It rejects transient design gimmicks, juvenile bouncy animations, and marketing buzzwords in favor of **quiet institutional authority, atmospheric visual depth, human typographic warmth, and rock-solid engineering hygiene**.

## ⚡ Quick Install

You can install the **Peace UI** skill into any project with a single command:

```bash
# Install directly into your current project (.agents/skills/peace-ui/)
npx peace-ui

# Or install for all major agent environments (Antigravity, Claude Code, Cursor)
npx peace-ui --all
```

Or install as a project dependency:

```bash
npm install -D peace-ui
```

Or clone directly into your project's skills directory:

```bash
git clone https://github.com/Peacsib/peace-ui.git .agents/skills/peace-ui
```

## 🏛️ The Core Pillars of Peace UI

### 1. Institutional Dominance & Anchor Hierarchy
Every high-trust system is backed by an anchor institution (a licensed bank, premier university, healthcare authority, or enterprise parent).
- **The Anchor Dominates**: The licensed bank or university anchors trust in visual scale and placement.
- **Sub-Brand Vector Cleanliness**: Channel logos (*EezySend*, *LogMate*) are clean monochromatic vector SVGs.
- **Sacred Casing**: Regulatory titles and names use exact canonical representations (`"EezySend REMITTANCE TRANSFER"`, `JOHN DOE`).

### 2. Atmospheric Depth & Frosted Glass Matrix
- **Layered Environmental Backdrops**: Golden-hour photography or deep institutional gradient meshes replace sterile white canvases.
- **Calm Glassmorphism**: Floating frosted containers (`backdrop-blur-xl`, `bg-slate-900/40` or `bg-white/80`, hairline borders `border-white/10` or `border-slate-200/80`).

### 3. Editorial Typographic Soul
- **Workhorse UI Sans**: Crisp, high-density sans-serif (Inter, Geist, Plus Jakarta Sans) for data tables, metrics, and inputs.
- **Expressive Italic Serif Accents**: Selective words in hero titles or section headers use warm, light italic serif or script styling (*"Your"*, *"Simplified."*, *"Back"*) for emotional warmth and prestige.

### 4. Domain-Adaptive Color Harmonies

| Domain | Anchor Palette | Accent & Highlight | Status / Semantics | Representative Work |
| :--- | :--- | :--- | :--- | :--- |
| **Academic & Professional (EdTech)** | Deep Academic Navy (`#0A3E94`) | Warm Amber / Golden Ochre (`#D97706`, `#F59E0B`) | Emerald (Active), Ochre (Pending) | **LogMate** (University of Zimbabwe) |
| **Fintech & Remittances (Banking)** | Forest Emerald (`#00332c`), Slate Charcoal | Jade Emerald (`#10b981`), Cobalt | Rust Orange (`#C7510A` Awaiting), Emerald (Collected) | **EezySend** (CABS / Old Mutual) |
| **Telemetry & Cloud Ops** | Obsidian Slate (`#020617`) | Electric Cyan (`#06b6d4`), Violet | Emerald (UP), Rust (`#C7510A` Degraded) | Cloud Infrastructure Dashboards |

### 5. Quick Capability Docks & Guided Progression
- Frosted horizontal capability cards anchored at the base of landing screens (`Track Placements`, `Keep Logbooks`, `Build Skills`, `Upload Evidence`).
- Multi-step form capsules (`Step 1 of 2 · Account Basics`) with contextual input formatting.

### 6. Quiet Security Signals (No Marketing Fluff)
- No boastful claims like *"256-bit unhackable military encryption"*.
- Understated quiet confidence: `<Lock /> Secure, encrypted connection` or `<ShieldCheck /> Secured`.

### 7. Author Signature & Human Craft Attribution
- Subtle creator credit in footers:
  > *"Crafted with excellence by Peace Sibanda"*
